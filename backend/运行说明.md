## 📋 常用命令

### 手动运行交易

```powershell
# 使用昨天的数据运行今天的交易
python scripts\run_daily_trading.py

# 运行指定日期
python scripts\run_daily_trading.py --date 2025-01-28

# 强制运行（即使周末也运行）
python scripts\run_daily_trading.py --force
```

### 查看报告

```powershell
# 生成每日报告
python scripts\generate_daily_report.py --date 2025-01-28

# 查看监控报告
python scripts\monitoring_system.py --days 7

# 查看优化建议
python scripts\optimization_system.py --days 30
```

### 管理定时任务

```powershell
# 查看任务
Get-ScheduledTask -TaskName "AITraderDailyTrading"

# 手动触发（测试）
Start-ScheduledTask -TaskName "AITraderDailyTrading"

# 删除任务（如需重新设置）
Unregister-ScheduledTask -TaskName "AITraderDailyTrading" -Confirm:$false
```

## 🎯 自动化后做什么？

设置完成后，系统会**自动运行**：

1. **每天 9:00** - 自动执行交易循环（无需操作）
2. **每天收盘后** - 可查看监控报告（可选）

你只需要：
- ✅ 定期查看监控报告（每周/每月）
- ✅ 根据优化建议调整策略参数
- ✅ 确保系统正常运行

## 🆘 遇到问题？

### 任务没运行？
- 检查任务是否启用：`Get-ScheduledTask -TaskName "AITraderDailyTrading"`
- 确认是工作日（周一到周五）
- 查看任务计划程序：`taskschd.msc`

### 运行出错？
- 查看错误信息（运行时会显示）
- 检查日志：`data\logs\monitoring.jsonl`
- 手动测试：`python scripts\run_daily_trading.py`

查看详细文档：
