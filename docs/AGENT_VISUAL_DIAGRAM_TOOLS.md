# 🤖 Agent 可视化图表工具推荐

## 🎯 需求说明

你想要创建类似示例图片的流程图，包含：
- **Agent 图标/头像**（机器人图标、卡通风格头像）
- **多 Agent 协作流程图**
- **清晰的 Agent 角色标识**

## 🛠️ 推荐工具（支持图标/头像）

### 1. **Whimsical** ⭐⭐⭐⭐⭐ (最推荐)

**网址**: https://whimsical.com/

**优点**:
- ✅ 内置丰富的图标库（包括机器人、人物头像等）
- ✅ 支持自定义图标
- ✅ 现代化美观界面
- ✅ 可以上传自定义图标
- ✅ 支持 Emoji 图标
- ✅ 手绘风格选项

**使用方法**:
1. 注册账号（免费版可用）
2. 创建 Flowchart
3. 添加节点时，点击图标按钮
4. 搜索 "robot", "agent", "avatar", "person" 等关键词
5. 选择合适的图标
6. 也可以上传自定义图标（PNG/SVG）

**适用**: 需要专业图标库

---

### 2. **Excalidraw** ⭐⭐⭐⭐⭐ (推荐，手绘风格)

**网址**: https://excalidraw.com/

**优点**:
- ✅ 手绘风格（类似示例图片）
- ✅ 可以导入图标/图片
- ✅ 支持 Emoji
- ✅ 免费开源
- ✅ 可以手绘头像

**使用方法**:
1. 打开 https://excalidraw.com/
2. 使用工具栏绘制形状
3. 点击 "Image" 按钮导入图标/头像
4. 或使用 Emoji（输入 emoji，如 🤖, 👤, 🎯）
5. 或手绘简单的头像

**适用**: 想要手绘风格 + 图标

---

### 3. **Draw.io (diagrams.net)** ⭐⭐⭐⭐

**网址**: https://app.diagrams.net/

**优点**:
- ✅ 支持图标库（从 draw.io 图标库导入）
- ✅ 可以插入图片
- ✅ 支持 Emoji
- ✅ 完全免费
- ✅ 功能强大

**使用方法**:
1. 打开 https://app.diagrams.net/
2. 创建 Flowchart
3. 添加形状后，右键 → "Edit Style"
4. 可以使用 Emoji（输入 emoji 文本）
5. 或插入图片（Insert → Image）
6. 或从图标库导入（需要安装扩展）

**图标来源**:
- 使用 Emoji（🤖, 👤, 👨‍💼, 🎯, 📊, 💼）
- 插入 SVG/PNG 图标
- 使用 draw.io 图标库

**适用**: 需要灵活性和免费方案

---

### 4. **Figma** ⭐⭐⭐⭐⭐ (最专业)

   - 免费图标库

   - 免费图标库
   - 包含大量人物和机器人图标

## 🔧 快速开始 - Whimsical (推荐)

### 步骤 1: 注册并登录
访问: https://whimsical.com/ 并注册账号

### 步骤 2: 创建 Flowchart
点击 "Create" → "Flowchart"

### 步骤 3: 添加 Agent 节点
1. 点击 "+" 添加节点
2. 输入节点名称（如 "Market Agent"）
3. 点击节点，右侧出现工具栏
4. 点击图标按钮 🔲
5. 搜索 "robot" 或 "person"
6. 选择合适的图标

### 步骤 4: 连接节点
使用箭头工具连接节点

### 步骤 5: 导出
点击右上角 "Export" → 选择 PNG 或 SVG
