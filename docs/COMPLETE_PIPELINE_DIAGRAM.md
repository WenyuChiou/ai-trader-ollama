═══════════════════════════════════════════════════════════════════════════════
                           完整循环流程
═══════════════════════════════════════════════════════════════════════════════

每 30 分钟循环:

1. 数据收集 (5-10 秒)
   └── fetch_market_batch() → market_view

2. Agent 分析 (30-60 秒)
   └── run_multi_analyst_discussion() → analyst_reports

3. 风险评估 (10-20 秒)
   └── run_risk_analyst_llm() → risk_report

4. 交易决策 (5-10 秒)
   └── run_trader() → buy_orders, sell_orders

5. 硬规则验证 (1-2 秒)
   └── 市场状态、现金、仓位限制检查

6. 订单执行 (5-10 秒)
   └── portfolio.buy/sell() → 更新持仓

7. 数据存储 (2-5 秒)
   └── 保存所有数据到 data/logs/

8. API 服务 (持续运行)
   └── 提供数据给前端

9. 前端显示 (实时更新)
   └── 显示所有数据和图表

总时间: ~2 分钟/循环
频率: 每 30 分钟
每日循环: ~13 次 (9:30 AM - 4:00 PM ET)
