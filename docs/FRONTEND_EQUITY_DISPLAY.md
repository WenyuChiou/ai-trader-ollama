# 前端净值显示逻辑说明

## 📊 净值记录显示方式

### 默认行为

前端默认显示**最近一周（week）**的数据，但会显示**所有符合条件的记录**（最多1000条）。

### 显示逻辑

1. **默认时间范围**：`period=week`（最近7天）
2. **记录限制**：`limit=1000`（最多显示1000条记录）
3. **实际显示**：显示所有在时间范围内的记录，不受30分钟间隔限制

### 示例

假设最近7天有以下净值记录：
- 2025-11-18 10:00:00Z
- 2025-11-18 10:30:00Z
- 2025-11-18 11:00:00Z
- 2025-11-17 14:00:00Z
- 2025-11-16 09:00:00Z

**前端会显示所有5条记录**（都在最近7天内），而不是只显示每30分钟一条。

### 时间范围选择

用户可以通过前端的时间范围选择器切换：
- **Day**: 显示最近1天的所有记录
- **Week**: 显示最近7天的所有记录（默认）
- **Month**: 显示最近30天的所有记录
- **Custom**: 自定义日期范围，显示该范围内的所有记录

### 关键点

- ✅ **不是**每30分钟更新一次显示
- ✅ **是**显示所有在选定时间范围内的记录
- ✅ 如果半小时内运行两次，两条记录都会显示（如果都在时间范围内）
- ✅ 记录数量取决于实际记录的数量，不是固定的
