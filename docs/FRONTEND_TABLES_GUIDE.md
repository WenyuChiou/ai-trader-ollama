# 前端表格说明文档

本文档说明前端监控界面中所有表格的用途、列定义和数据来源。

---

## 📊 表格总览

前端共有 **3个主要表格**：

1. **Current Holdings（当前持仓）** - 显示当前持有的股票
2. **Execution Details（执行详情）** - 显示交易执行记录（Overview页面）
3. **Trade Details（交易详情）** - 显示详细交易历史（Trade History页面）

---

## 1. Current Holdings（当前持仓表格）

### 📍 位置
- **页面**: Overview（仪表板页面）
- **位置**: 持仓区域（Holdings Section）
- **显示条件**: 有持仓时显示，无持仓时显示"No Positions"提示

### 📋 表格列定义

| 列名 | 说明 | 数据类型 | 示例 |
|------|------|----------|------|
| **Symbol** | 股票代码 | 字符串 | `AAPL`, `TSLA` |
| **Shares** | 持有股数 | 整数 | `10`, `25` |
| **Avg Cost** | 平均成本价 | 货币 | `$150.00` |
| **Current Price** | 当前市价 | 货币 | `$155.00` |
| **Market Value** | 市值（当前价格 × 股数） | 货币 | `$1,550.00` |
| **Unrealized P&L** | 未实现损益 | 货币 | `+$50.00` 或 `-$20.00` |
| **P&L %** | 未实现损益百分比 | 百分比 | `+3.33%` 或 `-1.25%` |
| **Weight** | 持仓权重（占总投资组合的百分比） | 百分比 | `15.50%` |

### 📊 表格特性

- **表尾（Footer）**: 显示总计行
  - Total Market Value（总市值）
  - Total Unrealized P&L（总未实现损益）
  - Total Weight（总权重）

- **颜色标识**:
  - 盈利行：绿色高亮（`profit-row`）
  - 亏损行：红色高亮（`loss-row`）
  - 盈利数值：绿色（`positive`）
  - 亏损数值：红色（`negative`）

### 🔄 数据来源

- **API**: `/api/portfolio`
- **数据字段**: `portfolio.positions` 和 `portfolio.positions_pnl`
- **更新频率**: 
  - 市场开放时：每30秒更新一次
  - 市场关闭时：显示最后快照

### 💡 用途

用于查看：
- 当前持有哪些股票
- 每只股票的持仓成本和当前价值
- 每只股票的盈亏情况
- 持仓在投资组合中的占比

---

## 2. Execution Details（执行详情表格）

### 📍 位置
- **页面**: Overview（仪表板页面）
- **位置**: AI Agent Conversations 下方
- **显示条件**: 始终显示（即使没有交易也显示空状态）

### 📋 表格列定义

| 列名 | 说明 | 数据类型 | 示例 |
|------|------|----------|------|
| **Time** | 交易时间 | 日期时间 | `11/14, 16:22:57` |
| **Symbol** | 股票代码 | 字符串 | `AAPL`, `TSLA`（可能包含"TOMORROW"标记） |
| **Side** | 买卖方向 | 字符串 | `BUY`（绿色）或 `SELL`（红色） |
| **Qty** | 交易数量 | 整数 | `10`, `25` |
| **Price** | 成交价格 | 货币 | `$150.00` |
| **Realized P&L** | 已实现损益 | 货币 | `+$50.00 (+3.33%)` 或 `-` |
| **Status** | 订单状态 | 字符串 | `FILLED`（绿色）或 `PENDING`（黄色） |

### 📊 表格特性

- **分页**: 每页显示50条记录
- **显示逻辑**:
  - 如果有FILLED订单：只显示FILLED订单
  - 如果没有FILLED订单：显示PENDING订单（包括明日挂单）
- **明日订单标记**: 如果订单是明天的，Symbol列会显示橙色"TOMORROW"标记
- **颜色标识**:
  - BUY订单：绿色（`trade-buy`）
  - SELL订单：红色（`trade-sell`）
  - FILLED状态：绿色（`status-filled`）
  - PENDING状态：黄色（`status-pending`）
  - 盈利：绿色（`trade-profit`）
  - 亏损：红色（`trade-loss`）

### 🔄 数据来源

- **API**: `/api/trades/recent?limit=100`
- **数据字段**: `trades` 数组
- **更新频率**: 
  - 市场开放时：每30秒更新一次
  - 市场关闭时：显示历史记录

### 💡 用途

用于查看：
- 最近的交易执行记录
- 已成交和待成交的订单
- 每笔交易的盈亏情况
- 交易时间线

---

## 3. Trade Details（交易详情表格）

### 📍 位置
- **页面**: Trade History（交易历史页面）
- **位置**: 交易详情区域
- **显示条件**: 切换到"Trade History"标签页时显示

### 📋 表格列定义

| 列名 | 说明 | 数据类型 | 示例 |
|------|------|----------|------|
| **Time** | 交易时间 | 日期时间 | `11/14/2025, 4:22:57 PM` |
| **Symbol** | 股票代码 | 字符串 | `AAPL`, `TSLA` |
| **Side** | 买卖方向 | 字符串 | `BUY`（绿色）或 `SELL`（红色） |
| **Qty** | 交易数量 | 整数 | `10`, `25` |
| **Limit Price** | 限价（订单创建时的价格） | 货币 | `$150.00` 或 `-` |
| **Fill Price** | 成交价格（实际成交价格） | 货币 | `$150.50` 或 `-` |
| **Price Range** | 价格范围（订单的价格区间） | 货币范围 | `$150.00 - $151.00` 或 `-` |
| **Realized P&L** | 已实现损益 | 货币 | `+$50.00 (+3.33%)` 或 `-` |
| **Status** | 订单状态 | 字符串 | `FILLED`（绿色）或 `PENDING`（黄色） |

### 📊 表格特性

- **分页**: 每页显示50条记录
- **显示所有订单**: 包括FILLED和PENDING
- **详细价格信息**: 显示限价、成交价和价格范围
- **颜色标识**: 与Execution Details相同

### 🔄 数据来源

- **API**: `/api/trades/recent?limit=100`
- **数据字段**: `trades` 数组
- **更新频率**: 
  - 切换到Trade History页面时更新
  - 手动刷新时更新

### 💡 用途

用于查看：
- 完整的交易历史记录
- 订单的详细价格信息（限价、成交价、价格范围）
- 所有订单状态（包括PENDING）
- 详细的交易分析

## 📊 表格对比

| 特性 | Current Holdings | Execution Details | Trade Details |
|------|------------------|-------------------|---------------|
| **显示内容** | 当前持仓 | 交易执行记录 | 交易历史详情 |
| **数据来源** | Portfolio API | Trades API | Trades API |
| **更新频率** | 30秒（市场开放） | 30秒（市场开放） | 页面切换时 |
| **分页** | ❌ 无 | ✅ 有（50条/页） | ✅ 有（50条/页） |
| **显示逻辑** | 所有持仓 | 优先FILLED | 所有订单 |
| **价格信息** | 平均成本、当前价格 | 成交价格 | 限价、成交价、价格范围 |
| **P&L类型** | 未实现损益 | 已实现损益 | 已实现损益 |
| **状态显示** | ❌ 无 | ✅ 有 | ✅ 有 |

## 🎨 颜色标识说明

### 持仓表格（Current Holdings）
- **盈利行**: 绿色背景（`profit-row`）
- **亏损行**: 红色背景（`loss-row`）
- **盈利数值**: 绿色文字（`positive`）
- **亏损数值**: 红色文字（`negative`）

### 交易表格（Execution Details & Trade Details）
- **BUY订单**: 绿色文字（`trade-buy`）
- **SELL订单**: 红色文字（`trade-sell`）
- **FILLED状态**: 绿色按钮（`status-filled`）
- **PENDING状态**: 黄色按钮（`status-pending`）
- **盈利**: 绿色文字（`trade-profit`）
- **亏损**: 红色文字（`trade-loss`）

---

## 🔍 数据去重机制

### Execution Details 和 Trade Details
- 使用 `symbol|side|quantity|price` 作为唯一键
- 自动去除重复的交易记录
- 价格保留2位小数进行匹配

---

## 📝 注意事项

1. **Execution Details** 和 **Trade Details** 使用相同的数据源，但显示逻辑不同：
   - Execution Details：优先显示FILLED订单
   - Trade Details：显示所有订单（包括PENDING）

2. **持仓表格** 只在有持仓时显示，无持仓时显示"No Positions"提示

3. **Realized P&L** 只在SELL订单且状态为FILLED时显示，其他情况显示 `-`

4. **明日订单标记** 只在Execution Details表格中显示，用于标识明天的挂单

5. **分页功能** 只在记录超过50条时显示分页控件
