# 本地访问共享网站说明

## ✅ 可以正常工作

无论你在自己的电脑上访问 `localhost` 还是自己的 IP 地址，都可以正常工作。

---

## 📋 两种访问方式

### 方式 1：本地访问（推荐，最简单）

**访问地址：**
```
http://localhost:3000
```

**前端自动连接：**
- 前端检测到 `localhost`
- 自动使用 `http://127.0.0.1:8000` 作为后端地址
- ✅ **可以正常工作**

**优点：**
- 最简单，不需要知道 IP 地址
- 不需要配置防火墙（本地访问）
- 适合自己使用

---

### 方式 2：使用自己的 IP 地址（共享网站）

**访问地址：**
```
http://192.168.4.24:3000  （使用你的实际 IP）
```

**前端自动连接：**
- 前端检测到 IP 地址 `192.168.4.24`
- 自动使用 `http://192.168.4.24:8000` 作为后端地址
- ✅ **可以正常工作**

**优点：**
- 可以分享给同一网络的其他设备
- 前端会自动适应 IP 地址
- 适合需要分享给其他人的情况

---

## 🔍 工作原理

### 后端配置

后端使用 `--host 0.0.0.0` 启动：
```bash
python -m uvicorn backend.src.api.server:app --host 0.0.0.0 --port 8000
```

这意味着：
- ✅ 监听所有网络接口（`0.0.0.0`）
- ✅ 可以接受来自 `127.0.0.1` 的连接
- ✅ 可以接受来自 `192.168.4.24` 的连接
- ✅ 可以接受来自局域网其他设备的连接

### 前端自动检测

前端 `config.js` 会自动检测访问方式：

| 访问地址 | 前端检测 | 后端地址（自动） |
|---------|---------|----------------|
| `http://localhost:3000` | `localhost` | `http://127.0.0.1:8000` |
| `http://127.0.0.1:3000` | `127.0.0.1` | `http://127.0.0.1:8000` |
| `http://192.168.4.24:3000` | `192.168.4.24` | `http://192.168.4.24:8000` |

## 🚀 使用步骤

### 步骤 1：启动后端

```powershell
# 在项目根目录
python -m uvicorn backend.src.api.server:app --host 0.0.0.0 --port 8000 --reload
```

或使用脚本：
```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\start_api_stable_bypass.ps1
```

### 步骤 2：启动前端

```powershell
# 在项目根目录
cd frontend
python -m http.server 3000 --bind 0.0.0.0
```

或使用脚本：
```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\start_frontend_share.ps1
```

### 步骤 3：访问网站

**选项 A：本地访问（最简单）**
```
http://localhost:3000
```

**选项 B：使用 IP 地址（可以分享）**
```
http://192.168.4.24:3000  （使用你的实际 IP）
```

## ✅ 验证

1. **打开浏览器开发者工具**（F12）
2. **访问网站**（`localhost` 或 IP 地址）
3. **检查 Network 标签**：
   - API 请求应该指向正确的后端地址
   - 不应该有 `ERR_NAME_NOT_RESOLVED` 错误
4. **检查 Console**：
   - 不应该有连接错误
   - API 请求应该成功

## ⚠️ 注意事项

1. **后端必须运行**
   - 无论使用哪种方式，后端都必须运行在端口 8000

2. **防火墙设置**
   - 如果使用 IP 地址访问，确保防火墙允许端口 8000 和 3000
   - 如果只使用 `localhost`，不需要配置防火墙

3. **同一网络**
   - 如果分享给其他人，他们必须连接到同一个 WiFi/局域网

---

## 🔧 故障排查

### 问题：访问 `localhost` 可以，但访问 IP 地址不行

**原因：** 防火墙可能阻止了端口 8000 和 3000

**解决：**
1. 检查防火墙设置（见 `docs/SHARING_SOP.md`）
2. 确保使用 `--host 0.0.0.0` 和 `--bind 0.0.0.0`

### 问题：前端显示错误的 API 地址

**原因：** 浏览器缓存了旧的 `config.js`

**解决：**
1. 硬刷新页面（Ctrl+F5）
2. 清除浏览器缓存
