## ✅ 2. 损益计算检查结果

### 2.1 加权平均成本 ✅

**测试结果**:
```
第一次买入: 10 @ $150 → avg_cost = $150.00
第二次买入: 5 @ $160 → avg_cost = $153.33 (加权平均)
```

**计算公式**:
```python
total_qty = existing.quantity + amount
total_cost = existing.total_cost + cost
avg_cost = total_cost / total_qty
```

**状态**: ✅ **正确**

### 2.2 未实现损益 ✅

**测试结果**:
```
持仓: 15 shares @ $153.33 avg cost
当前价格: $170.00
未实现损益: $250.00 (+10.87%)
```

**计算公式**:
```python
unrealized_pnl = (current_price - avg_cost) * quantity
unrealized_pnl_pct = ((current_price - avg_cost) / avg_cost * 100.0)
```

**状态**: ✅ **正确**

### 2.3 已实现损益 ✅

**测试结果**:
```
卖出: 8 shares @ $170.00
成本基础: $1226.67 (8 @ $153.33)
收入: $1360.00 (8 @ $170.00)
已实现损益: $133.33 (+10.87%)
```

**计算公式**:
```python
cost_basis = avg_cost * amount
proceeds = amount * price
realized_pnl = proceeds - cost_basis
realized_pnl_pct = (realized_pnl / cost_basis * 100.0)
```

**状态**: ✅ **正确**

### 2.4 部分卖出后的平均成本 ✅

**测试结果**:
```
卖出前: 15 shares @ $153.33
卖出: 8 shares @ $170.00
卖出后: 7 shares @ $153.33 (平均成本保持不变)
```

**逻辑**: ✅ **正确**
- 部分卖出时，平均成本保持不变
- 这是正确的会计处理方式
