# 🔒 只读模式说明

## 📋 功能概述

系统现在支持**自动只读模式**，根据访问方式自动启用：

- **本地访问** (`localhost` 或 `127.0.0.1`) → **完全控制** ✅
- **共享网站** (IP 地址，如 `192.168.4.24`) → **只读模式** 🔒

---

## 🎯 使用场景

### 场景 1：你自己使用（完全控制）

**访问方式：**
```
http://localhost:3000
```

**功能：**
- ✅ 可以执行交易
- ✅ 可以初始化系统
- ✅ 可以启动自动交易
- ✅ 可以查看所有数据
- ✅ 所有控制按钮都可用

---

### 场景 2：分享给其他人（只读模式）

**访问方式：**
```
http://192.168.4.24:3000  （你的 IP 地址）
```

**功能：**
- 🔒 **不能**执行交易
- 🔒 **不能**初始化系统
- 🔒 **不能**启动自动交易
- ✅ 可以查看所有数据
- ✅ 可以刷新数据
- ✅ 可以查看图表和对话

**自动保护：**
- 交易按钮自动隐藏
- 初始化按钮自动隐藏
- 自动交易功能自动禁用
- 显示 "🔒 Read-Only" 标识

---

## 🔍 工作原理

### 自动检测

系统通过检测访问的 `hostname` 来判断：

| 访问地址 | 检测结果 | 模式 |
|---------|---------|------|
| `http://localhost:3000` | `localhost` | 完全控制 |
| `http://127.0.0.1:3000` | `127.0.0.1` | 完全控制 |
| `http://192.168.4.24:3000` | `192.168.4.24` (IP) | 只读模式 |

### 只读模式保护

当检测到 IP 地址访问时，系统会：

1. **隐藏控制按钮**：
   - "▶️ Start Trading" 按钮隐藏
   - "⚙️ Initialize" 按钮隐藏
   - "Auto Demo Loop" 选项隐藏

2. **禁用自动交易**：
   - 自动交易功能不会启动
   - 显示 "Read-Only Mode (Shared)" 状态

3. **显示只读标识**：
   - 在页面顶部显示 "🔒 Read-Only" 标识
   - Auto Trade 状态显示为 "Read-Only Mode (Shared)"

4. **函数级保护**：
   - `startTradingCycle()` - 如果调用会显示警告
   - `initSystem()` - 如果调用会显示警告
   - `startAutoTrade()` - 自动跳过

## 💡 常见问题

### Q: 如果我想在本地也使用只读模式怎么办？

**A:** 可以手动修改 `frontend/monitor.html`，将 `isReadOnlyMode` 设置为 `true`：

```javascript
const isReadOnlyMode = true; // 强制启用只读模式
```

### Q: 如果我想在共享网站也允许交易怎么办？

**A:** 可以手动修改 `frontend/monitor.html`，将 `isReadOnlyMode` 设置为 `false`：

```javascript
const isReadOnlyMode = false; // 强制禁用只读模式
```

**⚠️ 警告**：这样做会允许任何人通过共享网站执行交易，存在安全风险。

### Q: 只读模式是否完全安全？

**A:** 前端保护可以防止普通用户误操作，但如果用户：
- 直接访问 API 端点
- 修改浏览器代码
- 使用开发者工具

仍然可能绕过前端保护。如果需要更强的保护，建议添加后端验证。

## 📝 技术实现

### 检测逻辑

```javascript
const hostname = window.location.hostname;
const isReadOnlyMode = hostname !== 'localhost' && 
                       hostname !== '127.0.0.1' && 
                       hostname !== '' &&
                       /^(\d{1,3}\.){3}\d{1,3}$/.test(hostname);
```

### 保护机制

1. **UI 隐藏**：控制按钮通过 CSS `display: none` 隐藏
2. **函数检查**：所有关键函数开头检查 `window.READ_ONLY_MODE`
3. **自动禁用**：自动交易功能自动跳过启动
