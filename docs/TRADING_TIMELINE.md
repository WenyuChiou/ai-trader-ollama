# ⏰ 交易时间线说明

## 📅 当前系统的时间流程

### 实际流程（当前实现）

```
Day N (例如: 2025-01-28)
├─ 运行时间: 早上 09:00（开盘前）
├─ 分析数据: Day N-1 的收盘价（昨天，2025-01-27）
├─ 生成订单: BUY/SELL 订单（基于昨天的分析）
└─ 执行时间: Day N 开盘后（立即执行，使用昨天的收盘价作为执行价格）
```

**具体示例**：
- **今天 (1月28日) 早上 09:00**：运行脚本
- **分析数据**：1月27日的收盘价
- **生成决策**：买入 NVDA @ $150.25（昨天的收盘价）
- **执行时间**：1月28日开盘后（使用昨天的收盘价 $150.25 执行）

## 🔄 两种工作模式对比

### 模式 1：当前实现（今天分析，今天执行）

```
时间线：
  Day N-1 (1/27)          Day N (1/28)            Day N+1 (1/29)
  收盘后 16:00    →    开盘前 09:00   →    开盘后 09:30
                          │
                          ├─ 运行脚本
                          ├─ 分析：1/27 收盘价
                          ├─ 生成订单
                          └─ 执行：使用 1/27 收盘价

订单类型：当天的交易订单
```

**优点**：
- ✅ 立即执行，不需要等到明天
- ✅ Portfolio 状态实时更新

**缺点**：
- ⚠️ 使用的是昨天的收盘价（可能与今天开盘价有差距）

---

### 模式 2：你理解的方式（今天分析，明天执行）

```
时间线：
  Day N (1/28)            Day N+1 (1/29)
  收盘后 16:00    →      开盘后 09:30
      │                       │
      ├─ 运行脚本              └─ 执行订单
      ├─ 分析：1/28 收盘价
      └─ 生成订单（明天执行）

订单类型：明天的交易订单
```

**优点**：
- ✅ 使用当天的收盘价（数据最新）
- ✅ 有时间审核订单（手动或自动）

**缺点**：
- ⚠️ 需要等到明天才能执行
- ⚠️ 明天的开盘价可能与今天的收盘价不同
