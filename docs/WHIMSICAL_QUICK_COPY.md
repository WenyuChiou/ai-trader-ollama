# 🚀 Whimsical 快速复制 - 一键创建流程图

## 📋 方法 1: 文本大纲导入（最简单）

### 复制以下文本，粘贴到 Whimsical

1. 打开 Whimsical: https://whimsical.com/
2. 创建新的 **Mind Map**（思维导图）
3. 点击中央节点，选择 "Import" 或直接粘贴以下文本：

```
AI Trader Agent System
├── Goal: Daily Trading Decision
├── 1. Market Agent
│   ├── Fetch Stock Prices
│   ├── Fetch VIX Data
│   └── Fetch Indicators
├── 2. Market Analyst
│   ├── Analyze Technical Patterns
│   ├── Analyze Sentiment
│   └── Generate Recommendations
├── 3. Analyst Discussion
│   ├── Round 1: Initial Consensus
│   ├── Round 2: Tool Execution
│   └── Round 3: Final Consensus
├── 4. Risk Analyst
│   ├── Evaluate Market Risk
│   ├── Evaluate Position Risk
│   └── Generate Control Report
├── 5. Trader Agent
│   ├── Evaluate Inputs
│   ├── Consider Risk Constraints
│   └── Make Decision
├── 6. Execution
│   ├── Execute Orders
│   └── Update Portfolio
├── 7. Backend Display
│   ├── P&L Display
│   ├── Trade History
│   └── Risk Metrics
└── 8. Evaluation & Feedback
```

**注意**: Whimsical 支持文本大纲格式，粘贴后会自动创建节点树！

## ⚡ 超快速方法（5 分钟完成）

### 步骤：

1. **打开 Whimsical** → 创建 Flowchart
2. **复制上面的节点列表**（方法 3 中的节点文本）
3. **在 Whimsical 中逐个创建节点**（快速输入）
4. **批量添加图标**：
   - 选中所有节点（Ctrl/Cmd + A）
   - 或逐个点击 → 图标按钮 → 搜索关键词
5. **快速连接**：
   - 使用快捷键或拖拽连接点
   - 按连接顺序列表连接
6. **调整布局**：
   - 自动对齐或手动调整
7. **导出**：PNG 或 SVG

## 🎯 提示

1. **使用模板**: Whimsical 有模板库，可以搜索 "workflow" 或 "process" 找到类似模板
2. **快捷键**: 
   - N: 新节点
   - A: 新箭头
   - G: 分组
3. **自动布局**: Whimsical 有自动布局功能，可以快速排列节点
4. **克隆**: 如果节点相似，可以克隆并修改

---

**最快方法**: 使用方法 1（文本大纲导入），几秒钟就生成整个结构！
