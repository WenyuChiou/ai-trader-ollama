# 📤 每日固定時間上傳到 Railway 設置指南

## 🚀 快速設置（推薦）

### 方法 1: 使用批處理文件（最簡單）

1. **右鍵點擊** `scripts\setup_railway_upload.bat`
2. **選擇** "以管理員身份運行"
3. **輸入** Railway URL（如果已配置可跳過）
4. **輸入** 上傳時間（例如：`18:00` 表示晚上 6 點）
5. **選擇** 工作日或每天（推薦：工作日）

**完成！** 系統將在您指定的時間自動上傳數據。

---

## ⚙️ 詳細設置步驟

### 步驟 1: 配置 Railway URL

**方法 A: 使用配置腳本（推薦）**

```powershell
python scripts\config_railway.py
```

**方法 B: 手動配置**

編輯 `railway_config.json` 文件：

```json
{
  "railway_url": "https://your-railway-app.up.railway.app"
}
```

**方法 C: 環境變量**

```powershell
$env:RAILWAY_URL="https://your-railway-app.up.railway.app"
```

### 步驟 2: 設置定時任務

**方法 A: 使用批處理文件（推薦）**

1. 右鍵點擊 `scripts\setup_railway_upload.bat`
2. 選擇 "以管理員身份運行"
3. 按照提示操作

**方法 B: 使用 PowerShell 腳本**

```powershell
# 以管理員身份運行 PowerShell
powershell -ExecutionPolicy Bypass -File scripts\schedule_railway_upload.ps1
```

## ⏰ 上傳時間建議

### 推薦時間

- **18:00** (晚上 6 點) - 市場收盤後，數據完整 ✅ **推薦**
- **20:00** (晚上 8 點) - 如果 18:00 太早
- **00:00** (午夜) - 如果希望第二天早上看到最新數據

### 運行頻率

- **工作日** (週一至週五) - ✅ **推薦**，只在交易日上傳
- **每天** - 如果希望週末也上傳

## 🔧 管理定時任務

### 手動執行任務

```powershell
Start-ScheduledTask -TaskName "AI-Trader-Railway-Daily-Upload"
```

### 刪除任務

```powershell
Unregister-ScheduledTask -TaskName "AI-Trader-Railway-Daily-Upload" -Confirm:$false
```

### 修改時間

1. 刪除現有任務（見上方）
2. 重新運行設置腳本：
   ```powershell
   powershell -ExecutionPolicy Bypass -File scripts\schedule_railway_upload.ps1
   ```

## 🐛 故障排除

### 問題 1: 任務沒有運行

**檢查：**
- 任務是否啟用：`Get-ScheduledTask -TaskName "AI-Trader-Railway-Daily-Upload" | Select-Object State`
- 任務觸發器是否正確設置
- 系統時間是否正確

**解決：**
- 手動測試：`python scripts\upload_data_to_railway.py`
- 如果手動測試成功，檢查任務觸發器設置

### 問題 2: 上傳失敗

**檢查：**
- Railway URL 是否正確
- 網絡連接是否正常
- 數據文件是否存在

**解決：**
```powershell
# 檢查 Railway URL
python scripts\config_railway.py

# 測試連接
python scripts\upload_data_to_railway.py
```

### 問題 3: 配置未保存

**檢查：**
- `railway_config.json` 文件是否存在於項目根目錄
- 文件是否有寫入權限

**解決：**
- 以管理員身份運行配置腳本
- 或手動創建 `railway_config.json` 文件
